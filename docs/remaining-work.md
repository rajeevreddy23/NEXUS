## Hosting constraint

No paid service, credits, overage setting or Render resource was created. All runtime test containers and volumes were deleted by CI. There is no permanent public URL. Continuous hosting of the complete persistent architecture, including isolated sandbox/database and real observability services, remains a separate infrastructure decision requiring suitable compute. Do not describe a GitHub Actions run as continuous hosting.

## Deliberate limits

Recovery clears only supported synthetic demo faults through RESET_FAULT. The system does not repair arbitrary infrastructure or application code. The topology is declared, diagnosis observes the injected demo mode, confidence is heuristic, sessions are process-local, one controller is supported, and the sandbox is a behavior replica rather than equivalent production staging. Provider availability and free quotas can change. These are documented scope boundaries, not features silently removed for cloud testing.
